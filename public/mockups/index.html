Medium moves from a dropdown to visual cards, because it decides which outputs are produced. Each card lists its deliverables, so the user knows up front that "Watercolor" means a value study + palette, and "Embroidery" means stitch outlines + thread colours.

03

Describe or upload — a composer, not a form

One big text area with tappable "add detail" chips replaces the six required fields. A reference photo is optional and side-by-side. Difficulty and duration are gone from this step — they become live sliders in the workspace, where their effect is visible.

04

Generating — show the stages

The paint-splat loader stays, but now tells the user what's happening. Concepts stream in one by one as each job finishes, so the first result appears in seconds instead of after one long spinner. Users can leave and come back — it's a background job.

05

Pick a concept — then refine

Four colour concepts to choose from, each with quick refinements ("simpler", "more like this", "different angle"). A side-by-side preview shows the derived line art, so the user picks based on how good the template will be, not just the pretty picture.

06

The workspace — layers and live sliders

The core screen. The template is computed in the browser from the chosen concept, so every slider updates instantly with no regeneration. Layers stack like Procreate/Figma (lines, values, grid, numbers, colour reference). Difficulty is now a real control: it changes region count and line simplification.

07

Palette & values — the painter's prep sheet

Extracted from the concept by colour clustering: named swatches with simple paint mixes, coverage percentages, and a value scale that matches the value study. Users can swap in their own paint set (e.g. "Winsor & Newton Cotman 12") and the mixes recalculate.

08

Project plan & journal

The template becomes a project: materials from the actual palette, numbered steps that reference the layers ("paint value 4"), time estimates, and a journal where users check off steps and add progress photos. This is what brings people back after the first visit.

Real print sizes with tiling across pages (for large canvases), a choice of which layers to include, and formats beyond PNG: a print-ready PDF pack (template + palette sheet + steps), SVG for Cricut/laser, and mirrored stencils.

10

Gallery — browse, filter, remix

A masonry gallery with filters for medium and difficulty. Hovering shows the finished piece next to its template (from journal photos). "Remix" starts a new project from someone's concept and settings, which is the community loop that keeps the gallery growing.
